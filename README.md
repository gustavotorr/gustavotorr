## Selected projects

Full documentation, code, CAD, and demo videos live in my **[Engineering-Portfolio](https://github.com/gustavotorr/Engineering-Portfolio)** — or browse the **[portfolio site](https://gustavotorr.github.io/Engineering-Portfolio/)**.

**[Adaptive Sliding-Mode Control of a 4-DOF Manipulator](https://github.com/gustavotorr/Engineering-Portfolio/tree/main/Adaptive-Sliding-Mode-4DOF-Manipulator)**
Nonlinear adaptive control doing pick-and-place with the payload mass underestimated by 57% — plus wall-impact contact dynamics. Euler–Lagrange derivation, Lyapunov stability, full technical report.

**[Statically Balanced Mechanism](https://github.com/gustavotorr/Engineering-Portfolio/tree/main/Statically-Balanced-Mechanism)**
A 3D-printed arm that holds its payload at any angle with zero holding torque. A spring and an analytically derived teardrop cam cancel gravity exactly over 360°. ([video](https://youtu.be/1I35prm3X8c))

**[Ball-and-Beam PID Controller](https://github.com/gustavotorr/Engineering-Portfolio/tree/main/ball-and-beam-pid)**
Arduino + time-of-flight sensor + servo balancing a ball in real time, with live PID tuning from an onboard joystick. ([video](https://youtu.be/9JrFDMzFvnI))

**[Bouncing-Ball Physics Simulator](https://github.com/gustavotorr/Engineering-Portfolio/tree/main/Bouncing-Ball-Physics-Simulator)**
Impulse-based collision model showing why heavier objects can stop sooner — friction at impact scales with mass.

**Other builds:** a solar-powered RFID pet feeder (senior design — Raspberry Pi, mobile app control) and Email Finder Scout, a published Chrome extension.
